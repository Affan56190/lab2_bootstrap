Task 5 - Custom UI: Semester Hub (Bootstrap version)
Rebuilt almost entirely with Bootstrap 5.3 components: navbar, nav-pills + tab-content (JS tabs
instead of the old radio-button hack), cards, progress bars, accordion, table-striped, list-group
with form-check, form-floating labels, form-range, btn-check "pill" buttons, and Bootstrap's built-in
data-bs-theme dark mode (toggled by a few lines of JS on the switch).
style.css only holds the 3D flip-card effect, which Bootstrap has no utility for.
Open index.html in a browser with an internet connection (Bootstrap loads from a CDN).
