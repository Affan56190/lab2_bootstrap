Task 1 - Class Timetable (Bootstrap version)
Rebuilt with Bootstrap 5.3 (CDN): container, table / table-bordered / table-hover / table-responsive,
contextual row/cell colors (table-primary, table-warning, ...), and badges for the legend.
style.css only holds the couple of tweaks Bootstrap doesn't provide.
Open index.html in a browser with an internet connection (Bootstrap loads from a CDN).
